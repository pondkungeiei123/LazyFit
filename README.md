# LazyFit V1.1

แอปสุขภาพส่วนตัวภาษาไทยสำหรับ Android 13 ใช้ React, TypeScript, Vite, Tailwind CSS, Capacitor และ SQLite ข้อมูลและรูปอาหารเก็บในเครื่อง แอป Android เปิดและบันทึกข้อมูลได้ในโหมดเครื่องบิน

## เริ่มบน Windows

ติดตั้ง Node.js 24 LTS และ pnpm 11 แล้วเปิด PowerShell ในโฟลเดอร์โปรเจกต์

```powershell
npm install --global pnpm@11
pnpm install --frozen-lockfile
pnpm dev
```

เปิด URL ที่ Vite แสดง พรีวิวเว็บใช้ SQLite ผ่าน WebAssembly และเก็บไฟล์ฐานข้อมูลใน IndexedDB ของ origin นั้น หากเปลี่ยนพอร์ตหรือเปิดหน้าต่างส่วนตัวจะใช้พื้นที่จัดเก็บคนละชุด

ตั้งค่าโปรไฟล์จากหน้า **วันนี้** หรือ **สุขภาพ** โปรเจกต์ในเครื่องมีไฟล์ `lazyfit-profile.local.json` สำหรับเลือกจากปุ่ม **เลือกไฟล์โปรไฟล์เริ่มต้น** ไฟล์นี้ถูก Git ignore และอยู่นอกโฟลเดอร์ที่ Vite ใช้สร้าง APK หากไม่มีไฟล์ ให้กรอกโปรไฟล์ด้วยตนเอง เป้าพลังงานเริ่มต้นแก้ได้ในหน้า **สุขภาพ**

## ทดสอบและสร้าง APK

```powershell
pnpm test
pnpm build
pnpm android:sync
pnpm exec cap open android
```

1. ใน Android Studio ติดตั้ง Android SDK Platform 35 ผ่าน SDK Manager และตั้ง Gradle JDK เป็น JDK 21
2. รอ Gradle Sync โหลด dependencies ในการ build ครั้งแรก
3. เลือก **Build → Generate App Bundles or APKs → Generate APKs** หรือใช้คำสั่งด้านล่างจาก PowerShell ที่ตั้ง `JAVA_HOME` ให้ชี้ไปที่ JDK 21 แล้ว
4. ใช้ Android Studio Run หรือ `adb install -r android\app\build\outputs\apk\debug\app-debug.apk` สำหรับ debug build เปิด USB debugging บนมือถือก่อนติดตั้งผ่าน ADB

```powershell
.\android\gradlew.bat -p android assembleDebug
```

ซอร์ส Android อยู่ใน `android/` แล้ว หลังแก้ UI ให้รัน `pnpm android:sync` อีกครั้งก่อน build APK การเปิด Android Studio ครั้งแรกและติดตั้ง dependencies ต้องใช้อินเทอร์เน็ต ส่วนแอปที่ติดตั้งแล้วใช้ฟีเจอร์บันทึกออฟไลน์ได้ [Capacitor Android](https://capacitorjs.com/docs/v7/android)

## พฤติกรรมใน V1.1

- **วันนี้** ดูพลังงานเทียบเป้า น้ำหนักล่าสุด XP/Level ภารกิจ 1–2 นาที ก้าวเดินและแหล่งข้อมูล พร้อมกราฟน้ำหนัก 7/30 วัน พลังงาน 7 วัน และนาทีออกกำลังกายรายสัปดาห์
- **อาหาร** ค้นหาอาหารไทย เลือกมื้อ บันทึกซ้ำจากประวัติ ปักเมนูโปรด ตรวจขนาดเสิร์ฟและปรับส่วนผสมก่อนบันทึก เพิ่มเมนูส่วนตัวและแนบรูปจากกล้องหรือไฟล์ได้ รูปที่บันทึกเป็น JPEG ด้านยาวไม่เกิน 900 พิกเซล
- **ออกกำลัง** แผน 7 วัน สตรีก วันพัก และตัวจับเวลา กดยืนยันเมื่อทำครบ เลือกภารกิจ 1/2/5/10/15 นาที รับ 3/10/20/30/40 XP ตามลำดับ ภารกิจแรกเพิ่ม 5 XP รวมสูงสุด 100 XP ต่อวัน ทุก 100 XP เพิ่มหนึ่งเลเวล วันพักไม่มีการหัก XP คะแนนใช้ในแอป
- **สุขภาพ** บันทึกน้ำหนัก รอบเอว และระยะเวลานอน ดูกราฟ 7 วันจากรายการล่าสุดของแต่ละวัน และแก้ไขโปรไฟล์ ระดับกิจกรรม หรือเป้าหมาย BMI ใช้น้ำหนักหารส่วนสูงเป็นเมตรยกกำลังสอง BMR ใช้ Mifflin–St Jeor และ TDEE ใช้ BMR × 1.2 [งานวิจัยต้นฉบับ](https://pubmed.ncbi.nlm.nih.gov/2305711/)

## ข้อมูลโภชนาการและการประมาณ

- แค็ตตาล็อกที่มากับแอปอยู่ใน `src/foodCatalog.ts` มีสูตรประมาณสำหรับอาหารและเครื่องดื่ม 40 เมนู กับส่วนประกอบ 33 รายการ ค้นหาได้จากชื่อ ชื่อเรียก และคำสะกดใกล้เคียง ค่าพลังงาน โปรตีน คาร์โบไฮเดรต และไขมันของส่วนประกอบมาจาก `food.csv` และ `food_nutrient.csv` ของ USDA FoodData Central, SR Legacy, April 2018 จับคู่ด้วย FDC ID และ nutrient ID 1008, 1003, 1005, 1004 ตามลำดับ ค่าต่อส่วนที่กินได้ 100 กรัม USDA เผยแพร่ข้อมูลภายใต้ CC0 1.0 [ชุดข้อมูล](https://fdc.nal.usda.gov/download-datasets/) · [สิทธิ์การใช้](https://fdc.nal.usda.gov/)
- Thai Food Composition Database ของสถาบันโภชนาการ มหาวิทยาลัยมหิดล ฉบับสิงหาคม 2025 เป็นแหล่งศึกษา มหิดลระบุว่าใช้เพื่อวัตถุประสงค์ไม่เชิงพาณิชย์ได้โดยให้เครดิต และให้ติดต่อเพื่อขออนุญาตทำซ้ำหรือเผยแพร่ ตัวแอปฝังเฉพาะข้อมูล USDA [เงื่อนไขและการอ้างอิงของมหิดล](https://inmu.mahidol.ac.th/thaifcd/content/1)
- สูตรและปริมาณเสิร์ฟเป็นสมมติฐานของ LazyFit ระบบรวมค่าจากส่วนผสมที่ระบุ แล้วปรับตามสัดส่วนน้ำหนักที่กินจริง ขนาดเล็กและใหญ่ใช้ประมาณ 75% และ 125% ของสูตรปกติ สูตรไก่และหมูใช้ค่าจากเนื้อส่วนไม่ติดมันที่ปรุงสุก ไข่เจียวใช้ค่าไข่ต้มและแยกน้ำมัน ชานมใช้ชาดำ นมสด และน้ำตาลตามที่แสดง สูตรร้านจริงอาจต่างกัน
- SQLite migration 3 ย้ายบันทึกอาหารเดิมรวมรูปและค่าเดิม เพิ่ม `food_catalog` สำหรับเมนูส่วนตัว และ `user_food_favorites` แค็ตตาล็อกในแอปมีสูตร ขนาดเสิร์ฟ ส่วนประกอบ และรหัสแหล่งอ้างอิงอยู่ในไฟล์เดียวเพื่อใช้ได้ออฟไลน์ ไฟล์สำรองเดิมยังนำเข้าได้ ค่าโภชนาการในบันทึกอ้างอิงน้ำหนัก base_grams รายการใหม่เก็บค่าที่กินจริงและตั้ง base_grams เท่ากับน้ำหนักที่กิน รายการที่ไม่มีข้อมูลโภชนาการจะแสดงว่าไม่ทราบและแยกจากยอดที่คำนวณได้
- `src/foodRecognition.ts` เตรียม interface สำหรับผลที่ต้องให้ผู้ใช้ตรวจสอบ รุ่นนี้แนบรูปในเครื่องได้และยังไม่มีโมเดลหรือการอัปโหลดรูป


## การจัดเก็บข้อมูล

- `src/schema.ts` กำหนดตาราง `profiles`, `weight_logs`, `waist_logs`, `food_logs`, `exercise_logs`, `sleep_logs`, `daily_activity`, `xp_events`, `app_settings` และ `sync_metadata` มีคีย์หลัก เวลาสร้าง/แก้ไข และคู่ `source + source_id` แบบ unique ส่วน `schema_migrations` ติดตามเวอร์ชันสคีมา
- `src/repository.ts` รวมธุรกรรมการบันทึก การกันข้อมูลซ้ำ การย้ายสคีมา และสำรองข้อมูล ก้าวอัปเดตแยกตามวันและแหล่งที่มา ตัวจับเวลาใช้รหัสเดิมเมื่อกดบันทึกซ้ำ และ XP ใหม่แยกคะแนนกิจกรรมกับโบนัส Migration 4 เก็บคะแนนเดิมและเพิ่มมื้ออาหาร ระดับกิจกรรม และวันพัก
- Android ใช้ SQLite ของ Capacitor Community SQLite ในพื้นที่แอป ปิด Android Auto Backup JSON ส่งออกผ่าน Android share sheet หรือดาวน์โหลดเมื่อใช้บนเว็บ การนำเข้าเป็นแบบรวมข้อมูลในธุรกรรมเดียวและให้ข้อมูลเดิมมีลำดับก่อนหากชนคีย์
- หากไฟล์จากอีกเครื่องมี XP ซ้อนจนเกินเพดานหรือมีโบนัสซ้ำในวันเดียวกัน แอปจะยกเลิกการนำเข้าทั้งไฟล์ ไฟล์สำรองมีรูปกับข้อมูลสุขภาพเป็นข้อความ JSON ควรเก็บในพื้นที่ส่วนตัว การล้างข้อมูลแอปหรือล้างข้อมูลไซต์อาจทำให้ฐานข้อมูลหาย ควรส่งออกก่อน

## Health Connect และ Redmi Watch 5 Active

Kotlin bridge ขอเฉพาะ `READ_STEPS` เมื่อผู้ใช้กดอนุญาต ตรวจ availability และสิทธิ์อีกครั้งก่อนอ่าน แล้วใช้ API aggregate ของ Health Connect สำหรับช่วงตั้งแต่เที่ยงคืนถึงเวลาปัจจุบันตามเขตเวลาของมือถือ เมื่อไม่มีข้อมูลจะแสดงสถานะว่าง หากมีค่าก้าวที่กรอกเอง แอปแสดงค่านั้นก่อนเพื่อลดการนับซ้ำ [คู่มือ Health Connect](https://developer.android.com/health-and-fitness/health-connect/get-started) · [คู่มือการอ่านก้าว](https://developer.android.com/health-and-fitness/health-connect/features/steps)

Android 13 ใช้ Health Connect จาก Play Store การมีสิทธิ์อ่านก้าวและการมีข้อมูลจาก Mi Fitness เป็นคนละสถานะ หาก Mi Fitness ยังไม่ส่งข้อมูลมาที่ Health Connect ให้เปิดดูยอดจาก Mi Fitness แล้วกรอกใน LazyFit ได้โดยตรง

## Checklist บน realme GT Master Edition / Android 13

- [ ] ติดตั้ง debug APK เปิดทั้ง 4 เมนู ตรวจภาษาไทยและแถบนำทางในแนวตั้ง
- [ ] เปิดโหมดเครื่องบิน นำเข้าโปรไฟล์หรือกรอกเอง เพิ่มมื้ออาหาร น้ำหนัก รอบเอว เวลานอน และก้าว ปิดแล้วเปิดแอปใหม่และตรวจค่าที่บันทึก
- [ ] ถ่ายรูปและเลือกรูปจากเครื่อง ทดสอบยกเลิก แล้วตรวจว่ารูปอาหารที่บันทึกยังเปิดได้ออฟไลน์
- [ ] ค้นหาด้วยคำว่า กระเพราไก่ และ ชาไทย ลองปักเมนูโปรด ปรับส่วนผสมและน้ำหนักที่กิน แล้วตรวจยอดพลังงาน/สารอาหาร ลองเพิ่มเมนูส่วนตัวและตรวจว่ายอดแสดงรายการที่ไม่ทราบ
- [ ] เริ่มเดิน 2 นาที สลับแอปแล้วกลับมา กดบันทึกเมื่อครบ ลองกิจกรรมที่สองในวันเดียวกัน แล้วตรวจโบนัส 5 XP เฉพาะครั้งแรกและยอดรวมสูงสุด 100 XP ต่อวัน
- [ ] ส่งออก JSON ไปยังพื้นที่ส่วนตัว นำเข้าไฟล์เดิมสองครั้ง ตรวจจำนวนรายการและรูปอาหาร
- [ ] เปิด LazyFit เมื่อ Health Connect ยังไม่พร้อม ทดสอบปฏิเสธสิทธิ์ อนุญาต แล้วเพิกถอนสิทธิ์และกดอ่านอีกครั้ง
- [ ] ทดสอบอ่านทั้งกรณีไม่มีข้อมูลก้าวและกรณี Health Connect มีข้อมูล ตรวจต้นทางของข้อมูลใน Health Connect และเทียบยอดใน LazyFit
- [ ] เทียบยอด Redmi Watch 5 Active ใน Mi Fitness ลองกรอกเองและลบค่าที่กรอกเอง ตรวจว่าข้อมูลจาก Health Connect แสดงกลับมาเมื่อมี
